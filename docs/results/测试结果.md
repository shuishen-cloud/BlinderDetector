## 三、安全关键规则的验证情况

以下几项测试验证的是**会实际致害的失效模式**，答辩时可单独指出：

| 验证的规则 | 对应用例 | 若失效的后果 |
| :--- | :--- | :--- |
| 风险升级不会被去重吞掉 | `test_escalation_breaks_dedup`、`test_dedup_key_changes_when_risk_escalates` | 台阶从 info 升到 danger 时被当成「重复」丢弃，用户撞上去 |
| 风险分级用悲观距离 | `test_pessimistic_distance_subtracts_sigma`、`test_sigma_changes_the_bucket` | 高估距离导致用户按错误预期迈步 |
| 对障碍物不播距离数字 | `test_obstacle_phrase_never_contains_a_number` | 虚假精确感让用户建立错误心理预期 |
| TTL 不小于播报耗时 | `test_ensure_ttl_extends_when_too_short` | 预警播到一半过期，用户两句话都没听懂 |
| 近距离自动降级为短句 | `test_fit_text_falls_back_to_terse_when_window_is_tight` | 完整句子物理上说不完，等于没报 |
| 置信度门限 | `test_low_confidence_is_not_published` | 误报累积导致告警疲劳，真预警被忽略 |
| 跌倒 `suspected` 永不提前外呼 | `test_no_notification_before_deadline`、`test_notifies_only_after_deadline` | 把手机扔到床上就打电话给家属 |
| 沉默不等于安全 | `test_silence_never_counts_as_safe`、`test_phone_dropped_on_ground_still_escalates` | 失去意识的人没有运动，被误判为「没事」 |
| 取消不依赖网络 | `test_cancel_does_not_need_network` | 断网时用户无法取消误报 |
| 绝不自动拨 120 | `test_never_auto_dials_emergency_services`（fall 与 sos 各一条） | 误报占用真实急救资源，法律责任最重 |
| 幂等防止重复呼叫 | `test_idempotency_key_prevents_double_call` | 网络重试变成三个电话打给家属 |
| 通知链去重键互不相同 | `test_notification_keys_are_distinct` | 网格员永远收不到通知 |
| **措辞不谎报「已送达」** | `test_wording_never_claims_delivery_happened`（fall 与 sos 各一条） | 说了「已通知家人」而其实没发出去，用户据此放弃自救 |
