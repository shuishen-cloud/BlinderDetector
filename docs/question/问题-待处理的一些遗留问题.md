## 四、部署前的阻塞项（2026-09-28 新增）

上线用的容器与 nginx 配置已补（`deploy/README.md`），但下面三条**不是配置能解决的**：

1. **★ 没有任何鉴权**。所有路由匿名可调用，而每一次感知/识别都在花部署者的
   dashscope 额度。挂公网前至少要加一层网关鉴权或按 IP 限流 ——
   现在把域名发出去，等于把 key 的消费权发出去。
2. **只能单进程**。紧急状态机与 `arbiter` 的已发 id 都在进程内存里，
   `--workers >1` 会把状态劈成互不相干的好几份，**而且不报错**，只是行为变诡异。
   要扩容得先把这两处状态外置（`sent` 那个改动见 §2.2，两件事可以一起做）。
3. **演示素材不在仓库里**。`data/demo.mp4` 与 `data/frames/*.png` 被 `.gitignore`
   排除，服务器上 clone 下来是没有的 —— 要手工拷（`deploy/README.md` 第 3 步）。

另外两条离部署最近、已在上面记过：**§2.1 上传目录可被 `/data/*` 直接读走**、
**§2.3 没有上传大小上限**（`deploy/nginx.conf` 的 `client_max_body_size 64m`
只是把 nginx 那层的口子收窄，应用层仍然随便收）。
